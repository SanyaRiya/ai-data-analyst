# AI Data Analyst Team

An AI-powered multi-agent data analysis platform built using FastAPI, React, and Gemini AI.

## Features

- Upload CSV/Excel datasets
- Automatic dataset understanding
- Data cleaning suggestions
- Statistical analysis
- AI-generated business insights
- Automatic chart generation
- PDF report generation

## Tech Stack

### Backend

- FastAPI
- Python
- Pandas
- Matplotlib
- ReportLab
- Gemini API

### Frontend

- React
- TypeScript
- Tailwind CSS
- Axios
